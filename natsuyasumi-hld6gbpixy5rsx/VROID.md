# VRoid Studio → Unity（2026-09-06）

**なぜ調べているか**：主人公の 絵を どう 用意するかの もう 1つの 道。
2Dの 生成には **中割りが 作れない** という 弱点が あり（D-225/D-226）、
3D（Meshy）は **顔が もたなかった**（D-223）。
VRoid は **顔が はじめから 描いた 絵**として 作られる ので、その 両方に 効く 可能性が ある。

---

## 入れた もの（済み）

`Packages/manifest.json` に UniVRM を 足した。**MIT ライセンス**（再配布 可・販売 可）。

| パッケージ | 中身 |
| --- | --- |
| `com.vrmc.gltf` | glTF の 土台（依存） |
| `com.vrmc.univrm` | **VRM 0.x** を 読む |
| `com.vrmc.vrm` | **VRM 1.0** を 読む |

VRoid は どちらの 形式でも 書き出せる ので 両方 入れて ある。
版は `v0.131.2`。Unity 2022.3 以降 対応で、変更履歴に `Unity 6000.5` の 直しが 入って いる。

戻すときは `Packages/manifest.json.bak` に 元が ある。

---

## 手順

### 1. VRoid Studio で 作って 書き出す

**VRoid Studio は 無料・アカウント不要でも つかえる。**（私は 入れられない ので 本人 作業）

1. モデルを 作る
2. `エクスポート` → `VRM エクスポート`
3. **VRM 1.0 を えらぶ**（迷ったら こちら。0.x でも 読める）
4. ポリゴン削減・テクスチャ削減は **かけなくてよい**。焼いて 使う なら 重さは 関係ない

### 2. Unity に 入れる

`.vrm` を `Assets/` の どこかに 置くだけ。UniVRM が 自動で 読み、
**Prefab ＋ Humanoid の Avatar ＋ マテリアル ＋ テクスチャ** を 作る。

★ここが 肝：**VRM は Humanoid として 入る**。だから
**人型の アニメーションなら 何でも 着せられる**（リターゲット）。

### 3. 歩きの モーションを 用意する

**VRoid には モーションは 入って いない。** べつに 用意して 着せる。

| 出どころ | 権利 | アカウント | 備考 |
| --- | --- | --- | --- |
| **Quaternius Universal Animation Library 1・2** | **CC0** | 不要 | 250以上。人型。**この企画は すでに Quaternius を つかって いる**ので 相性が よい |
| Kenney Animated Characters | **CC0** | 不要 | 数は 少ないが 確実 |
| CMU Mocap Database | 自由 | 不要 | BVH。数千。変換の 手間は ある |
| Mixamo | 無料 | **Adobe アカウントが 要る** | **私は 作れない**。本人が 要る |
| Unity Asset Store の 無料 | 商用可でも **再配布 不可** | 要 | **公開リポジトリには 入れられない**（この企画の 決まり） |

→ **Quaternius CC0 を 第一候補に する。**

着せかた：
1. FBX を `Assets/` に 置く
2. その FBX を 選んで Inspector → `Rig` → **`Animation Type` を `Humanoid`** → `Apply`
3. クリップを VRM の Prefab に 当てる（Animator ／ もしくは 焼く だけなら `Animator.Play` を コードで）

### 4. どう つかうか（この企画での 使い道）

**そのまま 3Dキャラとして 出すのでは なく、`marisa_walk.png` と 同じ
8列x10行の スプライトに 焼く。**

理由：
- 場面の 作り・カメラ・当たり判定は いまの まま で よい（実行時の 仕組みを 変えない）
- **中割りは アニメーションの 補間で 生まれる**＝2D生成の 弱点が 消える
- VRoid の 顔は **描いた 絵**なので、Meshy で 顔が もたなかった 問題も 起きにくい

焼く 道具は すでに ある（`Assets/Editor/MarisaYaku.cs`＝3Dモデルを 8方向x10行に 焼く）。
モデルと クリップが そろえば、それを VRM 向けに 直して 回すだけ。

## 注意

- **VRoid の 既定の 顔は VRoid の 見た目**。いまの 手描き 2Dとは 別人に なる。
  「元の 絵の よさを 残す」なら、**顔テクスチャを 差しかえる**か、
  VRoid 側で 目・眉を 描き直す 必要が ある（VRoid は 顔を 画像で 持つ ので 差しかえは 効く）
- 東方キャラの 権利は 本人の 領分。ここでは 触れない
- 使った モーション素材は **`CREDITS.md` と `REPLACE.md` に 必ず 書く**
