## 1. 村の骨格（北が山、南が村の入り口。川が東西に横切る）

```
            きた（山なみ・遠景）
  ┌──────────────────────────────────┐
  │ (拡張口:山の奥)   蛍の沢(夜)          │
  │   ひみつきち   森・ぬしの木            │
  │      │  山道(直角2回・30度坂)         │
  │ 鳥居─祠・杉木立だいら                  │
  │   石段(蹴上0.25)      池(金魚・ハス)   │
  │      ＼               │             │
  │ 駄菓子屋─橋═══川═══飛び石═══(拡張口:川下)│
  │    │      (釣り・水きり)              │
  │ 高台・火の見やぐら   田んぼ・あぜ道      │
  │    │         案山子・用水路(スイカ)    │
  │    └──幹線の道──┬──竹やぶ(余白)      │
  │              母屋・庭・井戸           │
  │           (縁側・ラジオ体操・物干し)     │
  └──────────────────────────────────┘
            みなみ（バス停・村の入り口）
```

- **母屋（拠点）**：南東の少し高い場所。DESIGN の「その夏だけの共同生活」の家。
  **2階の窓から祠の鳥居が見える**（綾部式：この構図のために祠の向きと杉の間隔を決める）。
- **幹線**：母屋→あぜ道→橋→祠の石段下。勾配10度以下・幅3.6m。全部の枝道はここから生える。
- **川**：村を東西に割る。渡り方は3つ＝橋（幹線）／飛び石（子どもの近道）／浅瀬（濡れる・夏だけ）。
- **山道**：直角2回曲がり（90度ずつカメラが回る・現行の学びを継承）で高台とは別の「奥」へ。

**連鎖**：高台→鳥居と山道の口が見える／祠→池の水面が光って見える／2階の窓→鳥居／
あぜ道→案山子越しに橋。**どこに居ても「次のしるし」が1〜2個見える**ように三角形（丘・木立）で
遮蔽を調整する（全部見えたら台なし。「ちらっと」が正しい）。

## 3. 動線（組む前に線を引く）

- 幹線1本（母屋⇔祠）＋枝5本（高台・駄菓子屋・池・竹やぶ・バス停）＋山道1本。
- **玄関→母屋の全部屋・2階**：戸口はすべて開口1.3m（OpenWall方式）。
- 川の渡り3つは難度違いの同じ答え（橋=安全／飛び石=楽しい／浅瀬=夏だけ）。
- 行き止まりは必ず「余白の何か」を置く（竹やぶの静けさ・バス停の時刻表）。用事ゼロの隅を最低2つ残す。

## 4-b. 道中表（R1の続き・2026-08-21）——幹線を歩く約70秒の中身

「祠までの距離は道中しだい」（D-102）の道中を決める表。**距離はこの表が埋まるほど伸ばしてよい**。
列＝場所（カメラの担当範囲と同じ名前）／そこで**見える**次のしるし／**できる**こと／**聞こえる**音。

| 場所（カメラ） | 秒 | 見える（引力のしるし） | できること | 音 |
|---|---|---|---|---|
| いえ・にわ | 0-8 | 物干しごしに 田んぼ、遠くに 鳥居の 頭 | 井戸で 水くみ（朝の 儀式）、体操 | 風鈴・にわとり |
| みちみなみ | 8-16 | 案山子の 赤い 頭巾、駄菓子屋の のれん（遠） | — （歩く。両わきに 何も 置かない 余白） | せみ（遠） |
| たんぼ | 16-28 | 用水路の きらめき、川面の 反射 | 虫とり（トンボ・バッタ）、案山子を 調べる | かえる・せみ |
| かわ みなみ／とびいし | 28-40 | 対岸の 道、橋の 欄干、（西に）駄菓子屋 | 水きり、飛び石わたり、釣り | 川の ごう音（近づくと 大きく） |
| はし | 40-46 | 橋の 上から 川の 抜け、鳥居（近） | ささぶね を 流す | 川 |
| かわ きた | 46-56 | 石段と 鳥居が 正面に | — （祠へ の 期待だけ。余白） | 川（うしろへ 遠ざかる） |
| いしだん | 56-64 | 鳥居の 見上げ | 石段を のぼる（それ 自体が 楽しい） | せみ（杉から） |
| ほこら | 64-70 | 杉ごしの 木もれ日、祠 | お参り、虫ずもう（大会の 場）、祭りの 予定地 | せみ・風 |

| いわば（枝道） | — | 飛び込み岩と 濃い 淵、足場の 岩 | **飛び込み**（最初は 怖くて 飛べない）、**ゴーグルで 潜る**、水泳大会（下旬） | 川・水に 入る 音 |

**枝道の誘い**（幹線から「ちらっと」見えるだけにして、行くかは本人に決めさせる）：
- はし→西の 川上流に 岩場の 頭（飛び込みの 気配）と 草ぎわ（ガサガサ）
- みちみなみ→西に 高台の やぐらの 頭（のぼれば 村が 見わたせる）
- たんぼ→東に 池の ハスの 緑（金魚・カエル）
- かわ みなみ→東の 浅瀬（濡れて 渡る 近道）、竹やぶ（余白）
- ほこら→北の 山道の 口（ひみつきち・蛍の 沢＝夜）

**この表の使い方**：R2の本組みでは、1行＝1カメラ＝1場面として距離と配置を微調整する。
「できること」が薄い行（みちみなみ・かわきた）は**意図した余白**なので埋めない。

## 5. R2（箱の村）の組む順

1. 地形の丘と川（幹線の勾配10度以下を Paths 方式で数値確認）

3. 部品プレハブ（家・小屋・祠・鳥居・橋・やぐら＝あたり付き箱の組）を1回ずつ作る
4. 配置 → Kensa → 見せ場10枚スクショ → 本人レビュー
5. 合格後に R3（光）へ。**絵（テクスチャ・部品差し替え）はその後**
