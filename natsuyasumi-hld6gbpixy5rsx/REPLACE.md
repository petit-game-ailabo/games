# 差し替えが必要なもの

**最終的に販売を考えている。** いま借りているもののうち、そのままでは売れないものを並べる。
テスト用に一時的に拝借したものも、**必ずここに足してから**作業を進めること。

## ★ 商用化チェックリスト（オーナー判断が要る棚卸し・2026-08-09）

磨き込みは十分に積んだ。**販売で詰まるとしたら法務/権利**。オーナーが判断する材料として並べる：

- [ ] **キャラ絵（R-001）**：Majstek素材が非商用 → 差し替え必須（下表 R-001）。**技術的な土台は用意済み**（`td/assets`差し替え＋クレジット1か所）
- [ ] **東方Projectの二次創作を「販売」する可否**：上海アリス幻樂団の二次創作ガイドライン適合が要る（同人頒布の範囲か、商業ラインか）。**キャラを差し替えても、東方キャラのまま売るならここが要判断**
- [ ] **『ぼくのなつやすみ』の名称**：オマージュ表記は良いが、商用の宣伝文で作品名をどう扱うか（誤認を招かない表現に）
- [ ] **素材ライセンス（商用OK・確認済み）**：タイル=ansimuz(CC0)／魚=CraftPix.net 2D Game Assets(OGA-BY・帰属必須)／虫=madameberry(CC0)／音=手続き生成(自作)。in-game（タイトル/ポーズ/ED）＋`CREDITS.md`に明記済み
- [ ] **プラットフォーム規約**：公開先（itch.io/自ホスト等）の規約・年齢/表現の要件

> 磨き（ゲーム内容）とは別トラックで、上記4〜5点の可否を先に固めるのが安全。特に2つ目（東方二次創作の商用可否）が最大の分岐。
