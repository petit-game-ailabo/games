# 依頼プロンプト：正面の走り 12コマ（2026-09-06・二版）

## 一版から何を変えたか

一版は **「沈み」を描かせようとして失敗した。**
「コマ2は8コマでいちばん体が低い」「身長を100として98/96/101/104」と書いたが、
これは **横から見た走りの教科書図**で、正面には効かない。

本人の指摘：「沈みはいらない、そんな走り方してる人間はいないよ。
人の走り方はそんなに上がったり下がったりしない」——そのとおり。
実際の走りの重心の上下は身長の3%ほどで、**正面からはほとんど見えない**。

二版の方針：

- **上下は動かさない。** 基準線より下がるコマは作らない。上は最大6px（身長の2%）だけ
- 動きは **脚・腕・ひねり** で出す。とくに **ひざの高さ** と **奥ゆき（手前／奥）**
- 1歩4コマ → **1歩6コマ**。上下動を無くすと4コマではつながらない（D-235の実測）
