# 検査

写真背景版（`photo/`）が こわれていないかを、実際に ブラウザで うごかして たしかめる。
見た目の ゲームなので、目で見ないと わからないことが 多い。
だから **写真を差しかえたり NPCを動かしたりしたら、かならず これを 流すこと。**

## じゅんび

```
pip install playwright
playwright install chromium
```

## うごかす

```
python tests/run_all.py            ぜんぶ（5〜8分）
python tests/run_all.py screens    名まえに screens を ふくむ ものだけ
python tests/test_day.py           1本だけ
```

ゲーム本体は 検査のなかで 一時的な HTTP サーバに のせる。事前に なにか 立ちあげておく 必要はない。
スクリーンショットは `tests/_out/` に出る（git には 入れない）。

## なにを 見ているか

| ファイル | 見ていること |
|---|---|
| `test_screens.py` | 6画面すべて 出発点が 床のうえ／ランダムに歩いても 床の外に出ない／全画面が つながる／会話が 最後まで進み 尽きたら 二度と開かない／**どのNPCにも じゅうぶん近づける床がある** |
| `test_talk_range.py` | 会話の近さを 画面のうえの距離ではなく **地面のうえの距離** で はかっているか（奥に離れても ちゃんと終わるか） |
| `test_morning.py` | 朝のながれが ざしき→いえのまえ→どま を通って 自由行動になる／ふとんで 日が変わる／2日目は 別のセリフ／3日目は しずか |
| `test_poses.py` | たいそうが おわったら すがたが もどる／切りかわりで まっくらになる／NPCが じっさいに 歩いて 出入りする／場面あけに かってに 会話が はじまらない |
| `test_day.py` | 切りかわりの幕が 白くない／画面を移ると 夕方になる／**キー操作だけで 歩いて ふとんに立てば 日が変わる** |
| `test_mukae.py` | 日ぐれに けーねが むかえに来る（6画面すべてから）／1日1回だけ／ねた つぎの日は また来る |

## 過去に これで 見つかった こわれかた

- 遠近の道で「上」を押しっぱなしにすると ふちで 止まる（壁ぞいに すべる処理が いる）
- 歩ける多角形の 下辺が 画面の外だと、y の おさえこみと 食いちがって **道の外に 取りのこされる**
- けーねを いろりの奥に置いたら、まわりが solid で **近づける床が なくなり 会話できない**
- フェードの 増える側と 減る側を 同じフレームで 走らせて、**画面を移ると 暗いまま 戻らない**
- 「たいそう中か」を 時こくの引き算だけで 見ていて、曲が おわっても はねつづける

## 検査を 足すときの めやす

- 「見た目」ではなく **状態** を たしかめる。`window._ctrl`（`?record=1` で 出る）に
  `dbg() / talk() / poses() / scene() / steps() / gdist()` が ある。
- 画面ごとに fps を はかること。ぜんたいの平均だと **1画面だけの 落ちこみを 見のがす**
  （ふとんの ぼかしで ざしきだけ 17fps だったのを これで 見つけた）。
