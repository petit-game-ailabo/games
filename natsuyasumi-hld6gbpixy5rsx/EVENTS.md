# イベント候補表（2026-08-21・採用判断用）

ぼくなつ全作＋なつもん＋オラ夏のイベント調査と、「夏×田舎（海より川）の懐かしい」調査を統合。
**判断欄に ◎採用／○保留／✕不採用 を書きこんで返してもらう**ための表。
「資産」＝奥行き版（Zashiki）で実装済みのコードが在り、R4で載せ替えられるもの。

## 設計の核（あるある調査 1500人アンケート等から）

1. **「少し危険」が最強のエモ**——飛び込み・肝試し・夜の虫捕り。緊張→達成の順で演出する
2. **五感トリガーが記憶の鍵**——ひぐらし・蚊取り線香・川で冷えたスイカ。音と匂い（演出）を厚く
3. **「終わりの合図」が切なさを作る**——夕方のチャイム・線香花火の最後・とうろう流し。1日の締めに置く
4. ぼくなつの骨格は5層：**日課＋日付行事＋自由遊び＋収集＋大人のドラマ**（全作共通）
