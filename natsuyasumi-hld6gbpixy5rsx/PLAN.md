### ★「書いたが誰も呼んでいない」を止める（2026-08-17）

遊び手からの指摘：「**`BugBook.Asa()` は定義1件だけの死にコード**です。`today` は永久に0、
`Azukari()` は何があっても0を返す。つまり虫は弱らず逃げず、ずかんの『よわって いる！』は
**いまのビルドでは絶対に画面に出ません**。報告に書かれた画面は、存在しません」
「同じ形の失敗が4回目です（`PlayHost.nikki` / `savedHour` / `Nikki.Today()` / `Asa()`）」

原因は、パッチに使っていた Python の `str.replace` が**当たらなくても黙って何もしない**こと。
「ok」と出るので通ったつもりになっていた。**直しかたは3つ**：

1. パッチスクリプトは**当たらなければ例外で止まる** `edit()` を通す
2. 新しく足した public メソッドは `grep -rc` で**呼び出し元が2件以上**あることを確かめる
3. 新しく足した表示文字列は、**それが写った画面**を撮ってから報告する

あわせて `today` は「人が入れてくれる値」をやめ、`Nikki` から**自分で取りに行く**ようにした。
人まかせにした値は、たいてい誰も入れない。

**日をまたぐ確認の道具がなかったのが大もと**なので `shot.ps1 -neru N` を追加
（寝る→日記→朝を実際に通す）。実測：3日に5匹捕り、7日の朝に5匹とも逃げて `Freed` が0→5。

### ★家の形（2026-08-16 に直した）

本人の指摘：「家の一部が自作3Dに色を塗ってる部分もあっておかしすぎる」。
**絵は貼ってあったのに箱に見えていた。原因は絵ではなく形**だった。3つ直した。

1. **屋根＝入母屋をメッシュで起こす**（`Assets/Editor/HouseRoof.cs`・新規）
   - それまでは**傾けた箱2まい**。棟が無いので空がすけ、妻がわは開けっぱなし、
     面はまっすぐで反りが無く、軒は板1まいの厚みしかなかった
   - **「輪(リング)を積む」で組む**：高さ t ごとに四角い輪を作り、輪どうしを面でつなぐ。
     奥ゆきは棟で0まで縮め、横は隅棟の位置で**縮むのを止める**。
     止めた先は x が動かず y だけ上がる＝**そのまま妻壁(垂直)になる**。
     入母屋の「寄棟＋切妻」は、縮みかたを途中で止めるだけで出る
   - 反りは Y(t)=t^1.34（棟がわが急・軒がわがゆるい）。軒先は t² で少しはね上げる
   - 棟・隅棟・破風板・鬼がわら・軒の小口・軒天・垂木・軒げたを足した
   - **面のまわす向きをまちがえると裏返る。** 下屋と庇だけ茶色い板に見えたのがそれ
     （上から軒天が見えていた）
2. **壁＝真壁づくりにする**（`BuildHouse.Skin`）
   - 日本の民家の壁は「白い面」ではなく**「木の枠にはめた白い面」**。柱・貫を外に見せる
   - 腰は**下見板**（1m まで）、上は漆喰、あいだに**水切り**。面が上下に割れてのっぺりが消える
   - **土間の上は吹きぬけ**にして外壁を軒げたまで通した（屋根を上げた分、
     壁が2.35mで止まっていると2.2m ぶん素どおしになる）。土間の梁も見せる
3. **障子・窓に桟を組む**。7.2m のまっ白な板がいちばん目に痛かった

**ついでに潰した地雷：マテリアルの貼りかた。**
箱の UV はどの面も 0〜1 なので、**貼りかたが1つだと 10.8m の壁と 0.6m の壁で
絵のこまかさが18倍ちがう**。下見板を10.8mの腰壁に貼ったら板のすじが1本も出なかった。
`FitMat()`（BuildZashiki）が面の大きさ(m)を受けて **1.5m＝絵1まい** にそろえる。

## ★ 2026-08-09 大方針転換：実写背景 → 2D見下ろしドット絵（**この節が最優先の正**）

本人と長く話した結論：**実写写真の上に絵（虫・物）を足すと必ず“浮く”／僕は写真に馴染む絵を起こせない**。
このデッドロックを解くため、**実写をやめて 2D見下ろしドット絵に切りかえる**（素材が一貫して揃う・数も豊富）。
- **参考**：『ほの暮しの庭』（夜廻スタッフ）＝田舎スローライフ×夜の不安。**昼＝楽しさ主役／夜＝不安と気配**、
  **営みの“網”**（農・釣り・採集…）、**自分の荒れた庭を手入れ**、郷愁。この**設計DNA**を借りる（絵柄は真似ない）。
- **絵柄・視点**：ドット絵の**見下ろし型**（本人決定）。世界タイルは**まず無料CC0で試作→後で有料判断**（本人決定）。
- **キャラ**：**東方のまま**（本人決定）。見下ろしの4方向は**あきらめ、左右反転のみ**（本人決定・当面は今の chars.js を流用）。
- **新しい置き場**：`td/`（2D試作）。実写版 `photo/` は残す（ロジックの参照元）。**イベント/会話/フラグ/昼夜 等のロジックは
  写真かタイルかに依存しないので、追って td/ に移植**（描画と素材だけ作り替え）。
- **虫相撲・ひまわり・川・自由研究**などの「子供の夏の遊び」は、この2D土台の上で“felt”に作る（孤立させず網に）。
