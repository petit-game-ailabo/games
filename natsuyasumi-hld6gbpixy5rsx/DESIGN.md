# 幻想郷のなつやすみ — 構想メモ v4

v2（会話ログ）＋ 実況動画の観察 ＋ 視聴後の決定を統合したもの。

---

## 0. 核心の問題への答え

> 「東方だと、ぼくなつの日本の田舎の雰囲気とか、人と人との絡みとか、
> 　小学生の夏休み感とか出すの難しいね。没入感を壊しちゃう」

これが最大の設計課題。原因をはっきりさせると：

**ぼくなつの芯は「子供の視点」「家族」「生活」の3本。東方キャラは全員が
妖怪／巫女／魔法使いで、子供でも家族でもなく、生活感もない。** だから乗らない。

### 解：3点セットで置き換える

#### ① 主人公を **チルノ** にする（子供枠は妖精が担う）

| ぼくなつ | 東方版 |
|---|---|
| ボク（小3） | **チルノ** — 無鉄砲、自称最強、後先を考えない＝小学男子そのもの |
| 地元の友達 | 大妖精、ルーミア、リグル、ミスティア、（てゐ、橙） |
| 大人たち | 霊夢、魔理沙、慧音、妖夢、紫 |

これで **C（大人の深い話は子供には意味がわからない）が東方のまま成立する**。
紫や慧音が意味深なことを言っても、チルノは「そーなのかー」で流す。
プレイヤーだけが少し引っかかる。ぼくなつのあの感じがそのまま出る。

慧音は寺子屋の先生なので、**ラジオ体操の判子を押す人**として完璧。

#### ② 「家族」を「その夏だけの共同生活」に置き換える

みんなで寝泊まりする拠点を持つ。＝ **これ自体が秘密基地**（動画メモの秘密基地要素と統合）。
当面は博麗神社（or 神社の裏の小屋）。**廃村の一軒家案は §4 の通り保留**。

- 朝ごはん：誰かが作ってる（妖夢が飯炊き、ミスティアが焼き鳥、萃香がなんか飲んでる）
- 夜：縁側でみんなでだらだら喋る
- 迎えが来る：日が暮れると大妖精が「もう帰ろうよー」と探しに来る

「家族」ではなく「夏の間だけ一緒に暮らす連中」。血縁がない分、
**帰る場所がある**という機能だけを綺麗に引き継げる。

#### ③ 〔保留〕「人がいない寂しさ」は、残された生活の痕跡で作る

> **素材の都合で当面は使わない（§4）。ただし発想としては生きているので残す。**
> 将来 2Dリアル背景に移行したときに、この方向が最も効く。

人と人の絡みの代わりに **人がいた気配** で郷愁を担保する。

- 日めくりカレンダーが8月で止まっている
- 引き出しに、誰かの使いかけのラジオ体操スタンプカード
- 軒下の風鈴、물干しロープ、土間、縁側、卓袱台
- 錆びたバス停の時刻表、閉まったままの駄菓子屋

**チルノたちは「昔ここにいた子供」の真似をして夏休みを過ごしている。**
これがこの企画の情緒の中心になると思う。

#### ④ 額縁（動画メモの冒頭案を採用）

> 幻想郷の今。チルノが「ねえ、昔さ、夏休みってあったよね」と言い出す。
> 本編はその回想。最後、その夏が終わって、二度と同じ夏は来ない。

- ノスタルジーが二重になる（プレイヤーの子供時代 ＋ キャラの「あの夏」）
- **もう戻れない**という終わり方が作れる（ぼくなつのラストの感情）
- **§4-b の「あなたの夏に彼女たちが隠れていた」という狙いに直結する**

## 1. 観察の整理（採用 / 検討 / 不採用）

### 音 — ここが最優先。◎全採用

動画メモで一番熱量が高かった部分。実装コストが低くて効果が最大。

| 観察 | 東方版 | 判断 |
|---|---|---|
| 朝はちゅんちゅん、昼はセミ、夕方は鈴虫、夜はカラス | そのまま | ◎ |
| 川・滝のそばだと水音が大きくなる | 音源からの距離で音量を変える | ◎ |
| 家では風鈴 | そのまま | ◎ |
| 階段のギシギシ | 縁側の軋み、砂利、草をかき分ける音 | ◎ |
| 家を出て冒険＝ポップな音楽 | 拠点を出た瞬間だけ短く鳴る | ◎ |
| **家族のクラリネット。音が聞こえたら縁側に行くと吹いてる＝音が示唆** | **ミスティアの歌／プリズムリバーの演奏が遠くから聞こえる → その方向に行くと何かある** | ◎ 翻訳が完璧にハマる |

**「音が示唆になる」は、マップを出さない設計と噛み合う。** 地図の代わりに耳で探す。

### 時間 — v2を改訂

| 観察 | 判断 |
|---|---|
| 時間はマップ移動で進む | ◎ 採用。**探索＝時間消費**になるので「今日はどこまで行くか」の判断が生まれる |
| 時計はない。空の色と虫の声で伝える | ◎ 採用。**v2で入れた時計HUDは廃止** |
| 時間切れで迎えが来る | ◎ 採用。大妖精が探しに来て強制帰宅 |

### 拠点・生活 — ◎採用

| 観察 | 東方版 | 判断 |
|---|---|---|
| 朝ごはんで家族が情報とアイテムをくれる | 「川に大きいのがいるらしいぜ。竿、持ってけよ」（魔理沙） | ◎ その日の目的が自然に提示される |
| お手伝いクエスト（トウモロコシ） | スイカを用水路で冷やす、薪を集める、洗濯物を取り込む | ◎ |
| 場所の指示が会話ベース（「家出てまっすぐね」） | そのまま | ◎ 地図がないことと一体 |
| クエスト結果が数日後のご飯に変わる | 冷やしたスイカが数日後の夜に出る | ◎ 生活と地続きな感じが出る |
| 夜はご飯のあとみんなでお話 | 縁側で全員集合。日替わりの雑談 | ◎ 掛け合いの見せ場 |
| 「寝る／日記をつける」を選んで1日終了 | そのまま | ◎ |
| ご飯の絵が毎日違う | 余裕があれば | ○ |

### 夏休みの風物詩 — ◎採用

- **ラジオ体操**（慧音が判子）＋ **スタンプカードが埋まっていく**。早起きしないと行けない
- **自由研究**：植物の観察日記。外の世界の植物を幻想郷の連中が不思議がる
- **かき氷**：チルノが作れる（氷の妖精なので当然できる）
- **秘密基地**：拠点そのものが秘密基地、で統合

### 移動制限 — ◎採用、v2を改良

| 観察 | 判断 |
|---|---|
| 道路封鎖じゃなく「ハチの巣があるから」＝子供らしい理由 | ◎ **v2の「キャラに頼むと道が開く」と組み合わせる** |

**理由は子供っぽく、解決はキャラで。**

| 塞がり方（子供の理由） | 解決 |
|---|---|
| ハチの巣がある | リグル（虫を操れる） |
| 草が背より高くて進めない | 妖夢 |
| 水が深くて渡れない | にとり／わかさぎ姫 |
| 犬が吠えてて怖い | 橙／椛 |
| 暗くて先が見えない | ルーミア（逆に暗くする方だが、そこがギャグ） |
| 倒木 | 魔理沙（派手に吹き飛ばす） |

### マップ — 要検討だが方針あり

| 観察 | 判断 |
|---|---|
| ゲーム内に地図がない（説明書に載ってる） | — |
| 地図がないから「そことそこ繋がってたの!?」の発見がある | ◎ この体験は絶対に残す |
| 全体像は掴めないが、子供の街の認識ってそんなもの | ◎ |

**案：チルノの手描き地図を道具として持つ。行った場所だけ描き足されていく。**
未踏の場所は空白。図鑑と同じ「埋まる喜び」になり、発見の驚きも壊さない。

### 採集 — ◎採用

| 観察 | 判断 |
|---|---|
| 釣りはウキを見ながら。大きさと種類が出る | ◎ |
| 蝶を捕まえると籠画面で大きさと見た目を確認 | ◎ v2の捕獲画面と同じ |
| 虫かごは実物大。籠の中心から見回すと捕った虫が並んでいる | ◎ **これは相当いい**。数字ではなく体積で成果を感じる |
| 虫かごが一杯だと「ポケットに入れる」選択肢 | ◎ 子供っぽさの塊。採用 |
| 目の前に出た虫もその場で網で取れる | ◎ |

### 一度きりの強い体験 — 採用したい

| 観察 | 東方版 |
|---|---|
| **おじさんの陶器を割る**。事前に「触るな」と言われていた → 割る → ショッキングな曲 → 罪悪感が尾を引く | 霊夢の賽銭箱／パチュリーの本／萃香の瓢箪を壊す。**チルノなら確実にやる** |
| おじさんが出かけた夜だけ戸締りされてなくて、こっそり蛍を見に行ける | 霊夢が異変で出かけた夜だけ、こっそり抜け出せる |

どちらも **1周に1回だけ**。多用すると効かない。

### 不採用 — ぼくなつの欠点は継がない

| 観察 | 判断 |
|---|---|
| バイオハザード式のラジコン操作 | ✕ 動画メモの通り操作しづらい。**普通の8方向移動にする**。ただし「知らない家の怖さ」は音・暗い室内・引きの固定カメラで別途拾う |
| アイテム切り替えにメニュー画面へ行く | ✕ **数字キー／ホイールで即切替**。そもそも持ち物を虫網・釣竿・虫かご程度に絞る |
| 絵がリアル風 | △ 素材の都合でドット絵。ただし**空・遠景・光の当て方**を丁寧にやれば郷愁は出せる |
| 大人の会話の「深さ」 | △ 東方の大人組で代替（0-①）。人間ドラマそのものは持ち込まない |

## 2. 1日の流れ（改訂版）

```
 朝  ラジオ体操（早起きすれば）→ 慧音の判子
  ↓
 朝食 誰かが「今日こんなのがあるぞ」と教えてくれる／道具を渡される／頼みごと
  ↓
 外へ 拠点を出た瞬間、短くポップな音楽
  ↓
 探索 虫を追う／川で釣る／塞がった道を誰かに開けてもらう／音のする方へ行く
      ※ マップを移動するたび時間が進む。時計はない。空の色と虫の声で分かる
  ↓
 夕方 ヒグラシ、カラス。空が焼ける
  ↓
 帰宅 自分で帰る or 大妖精が迎えに来る
  ↓
 夜  縁側でみんなの雑談（日替わり）
  ↓
 「寝る／日記をつける」→ 絵日記が1枚増えて1日終了
```

## 4-b. 将来のアートディレクション（重要）

> 「2Dだと夏の思い出に重ならない。
> 　**ぼくなつのような2Dのリアルな絵の中で動く3D東方キャラ**にしていきたい。
> 　ある意味、**自分たちの過ごした夏に実は東方が隠れていた**、みたいなことを想像させたい」

これがこの企画の最終的な狙い。ドット絵は**暫定**であって、目指す絵ではない。

- 背景：写実寄りの一枚絵（ぼくなつのプリレンダ背景と同じ役割）
- キャラ：その中を歩く3D東方キャラ
- 狙う感情：**「あの夏の風景に、見えていなかっただけで彼女たちがいた」**

いまのドット絵版は、この絵作りに辿り着くまでの**遊びの検証用**と位置づける。
ゲームデザイン（忍び寄る虫取り・捕獲画面・音・時間の流れ）はそのまま持ち越せる。

## 6. プロトタイプで分かったこと（proto/ ）

「忍び寄る虫取り」が本当に成立するかだけを 1画面で確かめた。

### 検証：同じ60秒で戦略を変えて自動プレイさせた

| 戦略 | つかまえた | にげられた |
|---|---|---|
| 走って突っこむ | **4匹** | 14匹 |
| 忍び寄る（警戒を見て止まる） | **18匹** | 0匹 |

### 途中で分かった、いちばん大事なこと

**最初の実装では走ったほうが効率が良かった（28匹 vs 10匹）。** 原因は2つ：

1. **走りの警戒上昇が足りなかった** → 走ると警戒半径が1.9倍に広がるよう変更。
   ふちにいても「なんか来た」と気づくようにした（`near = 0.35 + 0.65*…`）。
2. **虫が無限に湧いていた** ← これが本質。
   逃がしても即補充されるので、乱獲が最適解になっていた。
   **v3で書いた「逃げた虫はその日もう出てこない」を実装し忘れていた。**
   1日に出る虫を有限（18匹）にした瞬間、数字が逆転した。

> **教訓：ステルスを機能させるのは警戒ゲージではなく「資源が有限であること」。**
> 逃がすことに取り返しがつかないから、慎重さに意味が出る。
> 本編でも「その日その場所の虫は有限」を必ず守ること。

### 手ざわりの調整値（本編に持ち越す）

- 歩き 108px/s ／ 走り 236px/s
- 警戒は差し引き式：`aware += (rate - 0.5) * dt`
  → 立ち止まれば さめる。歩けば じわじわ上がる。走れば一瞬で振り切れる
- 警戒 0.36 で「？」、0.72 で「！」＋ふるえる
- 空振りすると 半径190px の虫が全部逃げる

### 絵の限界

**16x16のドット絵は、捕獲画面の「主役」には耐えない。** 拡大すると
ただの色の四角になる。今回は標本カードの額に入れて誤魔化したが、
これは §4-b（2Dリアル背景＋3Dキャラ）に移行する強い理由になる。

## 7. 次の方向：リアル背景の中を歩く（2026-07-27 の指示）

### 7-1. もらった構想

| 内容 | メモ |
|---|---|
| **意味のない小川を、石に飛び移りながら渡る** | 機能ではなく「子供がやりたくなること」。ゲーム的な報酬をつけない。**マップに余白があるはず** |
| **同じ建物でも、庭と庭の隅でカメラ位置が全然違う** | ぼくなつの固定カメラの本質。**画面＝記憶／印象の単位**。同じ場所でも切り取りが変わると別の記憶になる |
| **背景を田舎のリアル寄りの画像にする。ただし2D** | 「細かいところまで3Dで覚えているわけじゃない。印象というか**写真**というかで覚えてる」＝ 実写ベースは狙いと合致 |
| **キャラは当面いまのドット絵のまま** | 背景だけ先にリアルへ |
| **移動範囲は画像の中の道に合わせて制限** | 背景ごとに歩ける領域（道の形）を持たせる |

> 「余白」と「カメラ位置＝記憶」は、いまの9画面版に決定的に足りないもの。
> いまは「全画面が用事のある場所」になっている。用事のない画面・用事のない隅を作る。

#### 7-6-a. 会話の近さは「地面のうえの距離」で測る

最初は画面上のふつうの距離（`Math.hypot(dx,dy)`）で測っていたが、**遠近があるので
奥へ10px 動くのと 横へ10px 動くのでは 実際に離れる量がぜんぜん違う**。
結果、横に離れると会話が終わるのに、奥に離れてもいつまでも終わらない、という状態になっていた。

見かけの背の高さ `h` はカメラからの距離に反比例するので、

```
奥ゆき z = FOCAL / h
横     x = (画面のx - 画面の中央) / h
```

とすれば両方おなじ単位になり、`hypot` がそのまま地面のうえの距離になる。
**単位は「そこに立ったときの背の高さ」ぶん**なので、`TALK_R = 1.6`（1.6人ぶん）と
直感的に書ける。`FOCAL` は写真のおよその画角で、奥ゆきと横のつりあいを決める（既定 900）。

`?edit=1` では この範囲を緑の線で描く。**円ではなく、奥がすぼまった楕円**になるのが正しい。

#### 7-7-a. キャラごとに すがた（pose）を持たせる

**出た不具合**：ラジオたいそうが おわっても みんなが たいそうの動きを し続けていた。

曲より長い 40拍のあいだ ずっと `taisoOn` になっていたこと。

→ **その場面のキャラは ひとりずつ じぶんの `pose` を持つ**ようにした。

| pose | 見た目 |
|---|---|
| `idle` | ふよふよ浮いている（妖精なので） |
| `walk` | 目的地へ歩く。歩幅で はずむ・向きが変わる |
| `taiso` | 拍にあわせて はねる。4拍ごとに のびる |
| `gone` | もう そこに 居ない（描かない） |

たいそうの step が おわるときに `pose` を `idle` に戻し、`taisoT0` も無効値に戻す。
**「いつまで その動きか」を時こくの引き算で決めない。状態を持たせて 明示的に戻す。**

#### 7-7-b. 転送しない。歩いて 出入りする

- `{k:'move', list:[[だれ, x, y, 消えるか]], s:上限秒}` を追加。
  **NPCが 自分で歩いて 画面の外へ出ていく。** 全員が着いたら step が終わる。
- 画面の切りかわり `{k:'to'}` は、**いちど まっくらにしてから**（0.55秒）
  場所を入れかえ、また あかるくする（0.75秒）。以前は 一瞬の白フラッシュだけだった。
- **ごはんの あとは、みんなが 出ていってから やっと チルノが動ける。**

### 7-8. 白い切りかわりをやめ、日が変わる手がかりを出す（2026-07-29 その4）

**もらった指摘**
1. 画面切りかわりの 白いのが 目に いたい
2. 自動でキャラが歩くようになったので 転送感は なくなって よい
3. **40回ぐらい出入りしても 日が変わらない。2日目の判定はできている？**

**なおしたこと**

- **切りかわりの幕を 白 → 黒に。** `rgba(250,252,246)` を `rgba(7,10,8, ×0.94)` へ。
  幕がいちばん濃いときの画面の明るさは 12〜39（もとの画面は 73）。
- **日が変わる条件は「移動」ではなく「ざしきの ふとんで じっとしていること」。**
  判定じたいは動いていたが、**写真には ふとんが写っていないので 場所がわからなかった。**
  → **写真のうえに ふとんを かいた。** 敷きぶとん・夏の水色の掛けぶとん・
  めくり返した白い裏地・まくら。`blur(1.1px)` をかけて 写真の解像感に あわせる。
  掛けぶとんを たたみと はっきり色分けしないと、ただの白い板に見える。
- **移動しても 何も起きないのが そもそもの問題だった。**

  時計は出さない（原作どおり「時計はなく空の色と虫の声」）。

`fade += dt*3.2` / `fade -= dt*2.6` を **同じフレームで両方走らせていた**ため、
差し引き +0.6dt で `fade` が増え続け、**一度画面を移ると 暗いまま二度と戻らなくなった。**
→ 「くらくする」と「あかるくする」を if/else で はっきり分けた。
数値をいじるときは、増える側と減る側が 同じフレームで走らないか 必ず見ること。

**検証**：幕がいちばん濃いとき 12〜39（白飛びしない）／出入り38回で `dayT` が 1 に達する／
**キー操作だけで 左へ歩いて ふとんに立ち、じっとすると 2日目になる**／

#### 7-10-a. `ctx.filter` の ぼかしは 毎フレーム やらない

わけたあとに fps を 画面ごとに 測ったら、**ざしきだけ 17fps** だった（ほかは 61）。
ざしきだけ ふとんを かいていて、そこで `ctx.filter = 'blur(2.2px)'` を
**毎フレーム** 走らせていたのが 原因。canvas の filter は とても おそい。

→ ふとんは 動かないので、**はじめの1回だけ 別のカンバスに かいて（`bakeFuton`）、
あとは それを `drawImage` で のせる**。61fps に もどった。見た目は 変わらない。

動かない飾りを 写真のうえに 足すときは、必ず 焼いておくこと。
