## 定義と狙い（ここを外すと全部外れる）

> HD-2D ＝ ドット絵の進化系。昔ながらの「ドット絵」に「3DCG」の画面効果を加えた幻想的な世界。

- 目標は3つ：**①ドット絵にリッチなマテリアル ②動的で豊かなライティング ③ポストエフェクトでミニチュア風**。
- 狙うのは「**思い出補正された次世代グラフィック**」。レトロの正確な再現ではない。
- 飯塚氏の戒め：「**少し先の進化した表現を追うと、懐かしさではなく“古臭さ”になる**」。
  記憶の中で美化されたイメージを作る。

## 構成要素（すべて一次資料で確認済み）

| 要素 | 手法 |
|---|---|
| キャラ | ドット絵 18×32px 級。3D空間にビルボード配置。**ライトを受ける**（エミッシブ：ライト受けの比率を持たせ、マップごとに調整＝ライブアライブ方式） |
| 背景 | ローポリ3D＋ドット風テクスチャ。**ワールド投影UV**（上から投影）で貼ると回転してもピクセルグリッドが崩れない |
| 小物 | キャラと同サイズ帯は「**背面のない3Dモデル**」でよい（見える面だけのはりぼて） |
| DoF | **深め**の玉ボケ（Bokeh）＝ティルトシフト。「魅せる部分のドットをクッキリ、他はボヤけさせる」情報量コントロール。マップごとに値を調整 |
| その他ポストFX | Bloom（窓明かり・水面のエミッシブを滲ませる）／Vignette弱／ColorGrading。**色収差は常用せず演出の瞬間だけ**（BREAK時など） |
| ライティング | 「**舞台演出のようなスポットライト方式**」。画面の薄っぺらさはこれで消す。演出時は太陽光を切ってポイントライトだけにする |
| カメラ | 見下ろし固定パース。ピクセルパーフェクトは**追求しない**（DoFのにじみを許容し活用する設計）。戦闘は真正面でなく**斜め＋常時微揺らぎ** |
| 屋内 | スケール**1/2**で作って屋外とシームレス接続。ドアのトリガーでライト・ポストFX・カメラ距離を一括切替 |
| 動く背景 | 頂点カラー(RGB)で3種の揺れをブレンドする草木揺れ、スプラインの川、マスクで窓明かり明滅 |

## 後続作から分かった「レシピではなく再調合」

- ライブアライブ：コンセプトを「情緒」→「熱血」に変え、**DoF弱め・ビネットほぼ無し・色収差は採用**へ振り直した。
  HD-2Dの数値は作品のトーンごとに決め直すもの。
- トラスト（ドット絵側の知見）：3Dライティング下では**純白が浮く**のでグレー寄りに。輪郭の最暗色は RGB(24,24,24)。
- オクトパスII：地形を直線から**有機的な曲線**へ。イベント限定のカメラワークを追加。

## 解像度の罠（ライブアライブの実測）

- **Render Scale は 100% 固定**。7%下げただけでドットの見た目が大幅劣化する。
- **FXAA必須**。無いと背景が破綻する。ドットの1ピクセルはレンダリング解像度に敏感。

## Unity（URP）での再現手順

1. パースペクティブカメラ、**FOV 20〜30の望遠気味**・見下ろし30〜45度。2D Rendererではなく3D＋Volume構成。
2. キャラ：Pointフィルタのスプライトを Lit 系（Shader Graphで Sprite Lit 相当）でビルボード。
   「エミッシブ：ライト受け」比率のパラメータを持たせる。影は丸影デカールで軽くてよい。
3. 背景：ローポリ＋Pointフィルタのドット風テクスチャ。上面投影UV。
4. Volume：DoF(Bokeh・深め・フォーカスはキャラ距離)＋Bloom＋Vignette弱＋ColorGrading(コントラスト高め・影は青緑)。
5. ライト：Directional＋要所にスポット。夜・屋内はライトを絞り、キャラのエミッシブ比率で沈みを防ぐ。
6. Render Scale 100%＋FXAA/SMAA。
7. 屋内は1/2スケール＋トリガーで環境一括切替。

## なつやすみへの示唆

- いまの奥行き版は「ライティングが平ら／DoFなし」なので、**舞台照明＋深めDoF＋Bloom**を入れるだけで
  「はりぼて感」がかなり減るはず（HD-2Dの薄っぺらさ対策はまさにこの2つだった）。
- ドット絵キャラ（魔理沙 8方向）を活かすなら、この構成は今の作りと相性がよい。
  キャラを3D化する場合は 3d-to-2d-toon スキルの領分。
