# モジュール式レベル構築と造形ルール（一次資料からの書き起こし）

出典：

  http://blog.joelburgess.com/2013/04/skyrims-modular-level-design-gdc-2013.html
- 同「Fallout 4's Modular Level Design」GDC 2016 https://gdcvault.com/play/1023202/-Fallout-4-s-Modular

## キットの文法（Skyrim/FO4 の鉄則）

- キット＝「グリッドにスナップする文脈的な部品システム」。部品の総和を超える"文法"を持つ。
- **フットプリントは互いの倍数**（512の部屋と256の廊下は必ず噛み合う。384はいずれ隙間を生む）。
  ジオメトリはフットプリントの内側に収める（はみ出すと隣と交差する）。
- **ピボットは「接地面かつ中央」で統一し、決めたら貫く**（途中変更は数百インスタンスの手修正＝大惨事）。
- **壁・床・天井は別部品にする**（FO4の教訓：合体部品は破綻の温床。分けたら自由度が跳ねた）。
- **ドア口・窓口の寸法は全建物で統一**（プラグ＆ソケット：穴の規格が同じなら襖・障子・板戸を差し替えられる）。
- 優先順位：**汎用コア部品 → バリアント → 一点物（ヒーロー部品）**。「Generic = Versatile」。
  一点物を先に作りたがるのを我慢する。

## キットのストレステスト（「壁に刺さる階段・床のない2階」はここで潰す）

本番に置く前に、テスト専用シーンで：
1. **ループバックテスト**：同じキットでロの字に一周組んで、隙間なく閉じるか。
   ズレを「継ぎ当て部品」で隠さず根本を直す。
2. **積層テスト**：2階建てに積んで、床に厚みがあるか・2階に床部品が張られる構成か・Z-fightingがないか。
3. **階段テスト**：階段の上端高さ＝階高（壁高＋床厚）と一致するか。登り口・降り口の前に
   踊り場1マス分の空間があり、壁に埋まっていないか。
4. **角寄せテスト**：角部品を変な向きで寄せるなど、想定外の組み方をわざと試す
   （デザイナーは必ず想定外の使い方をする）。

## メトリクス（Unity＝メートル。現実より広く作る）

| もの | ゲームの定石 | 現実 |
|---|---|---|
| プレイヤー | カプセル 1.0×1.8m・目線1.5〜1.7 | — |
| 壁の高さ／厚み | 3.0m／0.1m以上（床にも必ず厚み） | 2.4m |
| 廊下・通路 | **最低2.0m＝プレイヤー幅の2倍以上** | 1.2m |
| ドア | 1.25×2.5m | 0.9×2.0m |
| 階段 | 蹴上0.1×踏面0.15m・勾配30〜35度・12〜16段で踊り場 | 18×28cm |

現実寸法どおりに作ると「狭く・複雑で・不自由」に感じる（カメラの視野が狭く移動が速いため）。
**メトリクステストマップ**（各幅の廊下・段差・ドアを並べた試験場）を最初に作り、実キャラで歩いて凍結する。

## 動線（circulation）——「扉のない部屋」を設計段階で防ぐ

- **間取りより先に、玄関→全部屋への動線の線を紙に引く。** 線が引けない部屋＝扉のない部屋。
- 2階建てなら**垂直動線（階段の位置）を最初に**決め、1階と2階の両方の間取りに同じ位置で描く。
- 幅は道標：広い通路＝主動線、狭い＝副動線と読まれる。
- 住人が実際にどう動くかという「ディエジェティック動線」が説得力を作る。現実の建築論理に沿うと
  プレイヤーが空間を「読める」。

## ブロックアウト（グレーボックス）

- 仮ジオメトリの3D下書き。**捨てるのが安い**のが本質。アートパス後の作り直しは高い。
- 手順：ラフスケッチ → 地面＋**スケールフィギュア（1.8mカプセルの物差し）**＋壁 → **即プレイテスト** → 反復。
- 歩いて検証：ドアを通れるか・階段を登れるか・移動のテンポ・カメラからの見え方。
- 最頻出の失敗は**スケール狂い**。スケールフィギュアを多用して早く発見する。
- **アセットを最初から置いて間取りを考えない**——「見た目は良いが構造破綻」の直接の予防策。
- 合格した仮ジオメトリと同じフットプリント・同じピボットのアセットで**1部品ずつ**差し替え、
  差し替え後にもう一度全動線を歩き直す。

## 既製キットを使うとき

- 導入日に「キットジム」シーンを作る：①全部品を1列に並べてピボットとサイズを目視
  ②基本部品だけで小屋1軒（1階＋階段＋2階＋ドア2枚）を組む ③ループバック・積層・角寄せの3テスト。
  合格した部品だけ本番で使う（megakitの「まず数字を出す」MegaKit.Dump はこの思想の実装）。
- スケール統一：基準キャラと高さ比較し、Import Scale で揃えてから。シーン内スケールは(1,1,1)。
- 「バリアントをまだ買い足すな」——基本部品だけで全体を組んでから。

## 日本家屋の寸法（尺モジュール）

- グリッド910mm（3尺）、**1間＝1820mm**（柱芯々）。畳≒1820×910。和室天井≒2.2m、鴨居≒1.8m。
- そのまま使うと1.8mキャラ＋引きカメラには狭い。定石に沿った補正（推論と明記）：
  (a) 比率（畳2:1・柱の等間隔・縁側と土間の段差）だけ写して全体を1.2〜1.4倍に拡大、または
  (b) キャラを1.5m級に小さくする。グリッドを「1マス=0.91m か 1m」に統一すれば
  尺モジュールはむしろモジュラーキットと相性がよい。
- なつやすみは主人公が子ども身長（CharacterController 1.0m）なので (b) 側が既に成立している。
  柱1間=1.8mの真壁づくり（BuildHouse）はこの原則と整合。

## なつやすみでの運用

- 新しい建物・大物を組むときは：紙の間取り＋動線 → グレーボックス（箱だけ）で `Kensa.Aruku` と
  実ビルド撮影 → 合格後に部品差し替え。
- 部品化するときはピボット「接地・中央」、寸法は 0.5m グリッドの倍数、あたりは部品プレハブ側に1回
  （3d-collision-testing スキル参照）。
